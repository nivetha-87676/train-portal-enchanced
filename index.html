🇮🇳 IRCTC and National Train Enquiry System (NTES) use RESTful APIs with JSON responses for modern integrations.

🔑 API Key vs JWT Authentication

API Key
  • Simple string identifier
  • Sent in request header
  • No expiry (until revoked)
  • No user-specific claims
  • Example: RapidAPI, OpenWeather
JWT (JSON Web Token)
  • Header.Payload.Signature
  • Stateless authentication
  • Has expiry (exp claim)
  • Carries user identity & roles
  • Example: IRCTC login, Firebase
// JWT Structure Example const token = "eyJhbGciOiJIUzI1NiJ9.eyJ1c2VySWQiOiIxMjMiLCJleHAiOjE3MDAwMDAwMDB9.signature"; // API Key in header const headers = { 'X-RapidAPI-Key': 'your_api_key_here', 'Authorization': `Bearer ${token}` };

📚 Case Study: IRCTC Online Railway Booking System

  • Scale: 1.4 million+ bookings per day; 1.5 crore users login daily during peak
  • Architecture: Microservices on AWS, REST APIs, Redis caching, CDN
  • Auth: JWT-based sessions with OTP 2FA via SMS (CDAC gateway)
  • Payment: RazorPay, PayU, NPCI UPI — tokenised card data (PCI DSS)
  • Tatkal Queue: Fairness-based queueing with wait-list seat prediction using ML
  • Challenge: 2023 — 25 lakh concurrent users in 60s for a flash booking window
  • Solution: Auto-scaling Kubernetes pods, distributed locking via Redis SETNX
  • NTES API: RESTful, returns JSON with train position, delay, and coach info
